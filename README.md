# HomeBuddy

The objective of HomeBuddy is to develop a user interface for a mobile application that enables the intelligent and dynamic monitoring and control of all electronic devices and household appliances within a home. The primary goal is to reduce and optimize energy consumption across all households, allowing users to save not only money but also contribute to environmental sustainability.

The application's key innovative feature lies in its ease of use, ensuring that users of all age groups can navigate it effortlessly. This accessibility enables users to learn how to prevent energy waste while simplifying their daily routines.

## Development Phases

[Phase 1](Phase1/ipc-phase1-T13+14-G4-HomeBuddy-report.pdf)
  - During this initial phase, research was conducted to identify similar applications in the market. This stage also involved analyzing potential users to determine the primary target audience for the interface.

[Phase 2](Phase2/ipc-phase2-T13+14-G4-HomeBuddy-report.pdf)
  - In this phase, a low-fidelity prototype was developed and subsequently evaluated by other students. Their feedback provided valuable insights into usability and functionality improvements.
    
[Phase 3](Phase3/ipc-phase3-T13+14-G4-HomeBuddy-report.pdf)
  - The final phase focused on refining the prototype based on prior evaluations. The high-fidelity version was then tested by real users through the Maze usability testing platform, ensuring optimal user experience and interface efficiency.
